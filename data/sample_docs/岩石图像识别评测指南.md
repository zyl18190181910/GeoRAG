# 岩石图像识别评测指南

岩石图像分类任务应先按原始图像或采集区域划分训练集、验证集和测试集，再进行裁剪与增强。同一原图产生的相邻图块不应跨越不同集合，否则可能发生数据泄漏，使验证指标虚高。

多类别识别可同时报告 Top-1、Top-3 和 Macro-F1。Top-1 表示最高分预测正确的比例，Top-3 衡量真实类别是否进入前三个候选。Macro-F1 对每个类别分别计算 F1 后取平均，更能反映少数类别的识别效果。

类别不均衡时还应查看每一类的精确率、召回率和混淆矩阵。混淆矩阵可以定位经常互相误判的岩性类别，帮助判断问题来自样本不足、标注边界不清还是视觉特征相似。

低置信度样本不应被强制归入已知类别。系统可以设置拒识阈值，并将低于阈值的结果标记为未知类别。阈值应在独立验证集上选择，同时比较误拒率与误识率。

数据增强只能应用于训练集。验证集和测试集应保持稳定，避免每次评测输入不同。增强策略需要符合地质图像的实际变化，不能使用会破坏岩层结构含义的变换。

模型测试除总体指标外，还应检查模糊、遮挡、尺度变化、光照变化和类别外样本。每个异常样本需要保留输入、模型版本、预测结果、置信度和复核结论，以支持问题复现与回归验证。

模型升级后应使用固定测试集执行回归评测，对比总体指标、各类别指标、拒识表现和典型异常样本。评测记录需要保存模型版本、数据版本、参数配置和运行环境。
